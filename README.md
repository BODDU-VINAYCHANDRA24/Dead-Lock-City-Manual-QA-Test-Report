# 🎮 Dead Lock City – Manual QA Test Report

## 📖 Overview

This repository showcases a self-initiated "Manual QA Testing" project conducted on the mobile game "Dead Lock City". The objective of this project was to evaluate gameplay quality, identify functional and performance issues, and document defects using industry-standard QA practices.

The testing focused on player movement, combat mechanics, zombie AI behavior, control responsiveness, UI interactions, audio feedback, and overall gameplay stability. All identified issues were documented with detailed reproduction steps, expected and actual results, severity levels, impact analysis, and supporting video evidence.

This project demonstrates my practical knowledge of manual game testing, gameplay analysis, defect reporting, and QA documentation.

---

## 🎯 Project Objectives

- Evaluate core gameplay functionality and stability.
- Validate player controls and gameplay mechanics.
- Identify gameplay, UI, audio, and performance issues.
- Document defects with reproducible steps.
- Provide structured bug reports with severity classification.
